🗂 Receipts in many views

The same database shown as a table, calendar, gallery, and board — flip between them live. The gallery shows each receipt's photo + cozy-pantry card; the calendar shows the days you shop.

Why it's the right Notion beat: "one database, many views" is Notion's signature trick. No formulas, no code, grandma-simple. You just switch tabs on stage.

Build plan — 7 days to June 12

Phase 1 · Make it readable (the core fix)

Move the two raw tables into a "See every item" toggle. Title the 3 charts. Add the hero month-spend Number chart + the category/top-list. Result: a verdict-first dashboard.

Depends on: nothing. Start here. · Mostly API once + manual layout once

Phase 2 · Shrinkflation Detective ∥ parallel with Phase 3

Generalize the price line beyond oat milk to the items that actually moved. Wire the bot to keep the "Price Watch" callout fresh.

Depends on: Phase 1 layout. Parallel with Phase 3. · API + bot

Phase 3 · Receipts in many views ∥ parallel with Phase 2

Add Calendar, Gallery (receipt photos + cozy-pantry cards), and Board-by-store views on the existing database. One database, many ways — Notion's signature move, no formulas, no code.

Depends on: nothing. API or manual once then native

Phase 4 · Food Group + Health Tier (unlocks the good breakdown + health bar)

Add two Item fields the model already computes; the bot writes them. Turns the 94%-Groceries donut into a real Produce/Meat/Dairy story, and lights up the health mix.

Depends on: a small schema + write change. Charts via API. · bot

Phase 5 · Lean on Notion automation

Replace any recap cron with Notion's native "Every week" automation. Fewer moving parts.

Depends on: Phases 1–2. · native
